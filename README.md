## 📁 Project Structure

The repository contains multiple Excel assignments, with each workbook focusing on a specific group of Excel functions.

### 1. IF & Logical Functions

This project focuses on using logical formulas to evaluate conditions and categorize data.

Examples include:

- Determining whether a student has passed or failed
- Assigning grades using Nested IF
- Identifying weekdays and weekends
- Calculating commission rates based on sales
- Categorizing expenses into High, Medium, and Low
- Evaluating students using IF + AND
- Determining eligibility using IF + OR
- Checking employee bonus eligibility
- Identifying products that are out of stock
- Evaluating candidate interview eligibility

The assignment includes practical examples of `IF`, `Nested IF`, `AND`, and `OR` formulas. 

---

### 2. Text Functions

This project focuses on manipulating and extracting information from text strings.

Functions covered include:

- `CONCATENATE`
- `TEXTJOIN`
- `LEFT`
- `RIGHT`
- `MID`
- `FIND`
- `LEN`
- `TEXT`

Examples include:

- Combining first and last names
- Extracting characters from strings
- Extracting portions of names
- Formatting dates
- Formatting numbers as currency
- Using FIND and LEN to work with names and text

---

### 3. COUNTIFS, SUMIFS & AVERAGEIFS

This project focuses on performing calculations using multiple criteria.

Examples include:

- Counting students who scored above a specific mark in both Math and Science
- Calculating total sales for a particular region and product category
- Calculating average salaries for employees based on department and experience
- Counting completed orders placed during a particular month
- Calculating revenue for products above a specified sales value within a category

These tasks demonstrate the practical use of `COUNTIFS`, `SUMIFS`, and `AVERAGEIFS` for multi-condition analysis.

---

### 4. Lookup Functions

This section focuses on retrieving information from datasets using lookup and reference functions.

Functions include:

- `VLOOKUP`
- `XLOOKUP`
- `HLOOKUP`
- `INDEX`
- `MATCH`
- `INDEX + MATCH`

Practical applications include:

- Finding employee information using Employee ID
- Retrieving product prices
- Finding department or job information
- Matching customer records
- Looking up sales information
- Retrieving values from horizontally and vertically structured datasets

The objective is to understand both traditional lookup methods and modern Excel lookup techniques.
